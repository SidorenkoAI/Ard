# Умный Свет

## Описание
Проект реализует автоматическое управление освещением на основе данных с датчика движения и освещённости.

## Компоненты
- Arduino UNO
- PIR-датчик
- Фоторезистор
- Светодиод
- Резисторы

## Авторы
- Иванов И.И. (логика)
- Петров П.П. (датчики)
- Сидоров С.С. (интерфейс)

## Как запустить
1. Подключите компоненты по схеме.
2. Загрузите код в Arduino IDE.
3. Откройте монитор порта.
